Bạn muốn làm gì?

Chọn một việc bên dưới. Tool sẽ dẫn bạn từng bước đến khi có file import cho KiotViet.

Quy trình 4 bước
  1. 1. Chọn ngành
    Tool tự chuẩn bị đúng các danh mục cần import cho ngành đó.
  2. 2. Nhập dữ liệu
    Dán bảng từ Excel hoặc tải file vào từng danh mục; tool tự ghép cột.
  3. 3. Kiểm tra
    Tool báo lỗi (trùng mã, thiếu tên, sai số…) và đưa bạn tới đúng ô cần sửa.
  4. 4. Tải về
    Nhận 1 file ZIP: các file đánh số theo thứ tự import + hướng dẫn.

C. Kiểm tra ghép cột

Mỗi dòng là 1 cột cần có trong file import. Dòng nền đỏ là cột bắt buộc chưa có dữ liệu → chọn cột tương ứng hoặc nhập giá trị mặc định.

Cài đặt file mẫu KiotViet

Làm một lần. Trên KiotViet, vào màn hình của danh mục (vd Khách hàng) → bấm Import → tải file mẫu về, rồi bấm Tải file mẫu ở đúng dòng bên dưới. Từ đó tool xuất đúng 100% theo file của KiotViet.

Áp dụng cho:
🧩 Nâng cao: định dạng cột “Món thành phần” của combo

Nếu KiotViet không nhận thành phần combo: tạo tay 1 combo có thành phần trên KiotViet → bấm Xuất file ở màn hình Thực đơn → tải file đó lên đây để tool học đúng cách ghi.
