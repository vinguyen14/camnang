Quy trình nạp menu & Import chuẩn:

Mô phỏng hành động chính xác trên KiotViet

1. Chọn mô hình từ Thư viện
Tự động nạp Thực đơn, Phòng bàn, Kho NVL.
2. Kiểm tra cờ "Dịch vụ tính giờ"
Giờ hát/Bida/Phòng khách sạn phải bật cờ này.
3. Tích chọn để sửa hoặc xóa món
Chọn 1 hoặc nhiều dòng để xóa nhanh.
4. Bấm "Xuất File Excel Đa Sheet"
Tải file .xlsx có đủ các Sheet chuẩn KiotViet.
5. Import lên KiotViet
Vào Thực đơn $\rightarrow$ Import $\rightarrow$ Chọn file!
